##  About
<div align="center">
<span style="color: #FF69B4; font-weight: bold;">양치 시간이 지루하고 귀찮게 느껴지나요?</span>

## Purpose
비급여 치과 진료 비용 부담을 줄이고, 게임화된 보상 시스템으로 재미있는 양치 습관을 만들어주는 서비스입니다.

<br>

##  Features

<table>
<tr>
<td width="50%">

###  퀘스트 시스템
매일 4개의 미션을 통해 치카코인 획득
- 양치 미션 3회 (아침/점심/저녁)
- 퀴즈 미션 1회

</td>
<td width="50%">

### 🦷 양치 애니메이션
3분간의 시각적 양치 가이드
- Lottie 기반 부드러운 애니메이션
- 올바른 양치법 교육

</td>
</tr>
<tr>
<td>

###  치아 건강 퀴즈
재미있게 배우는 치아 상식
- OX 문제 2개 + 객관식 1개
- 점수 기반 보상 시스템

</td>
<td>

###  스마트 알림
PWA 기반 푸시 알림
- 양치 시간 리마인더
- 네이티브 앱 같은 경험

</td>
</tr>
</table>

##  Getting Started

```bash
# Clone repository
git clone https://github.com/Leets-Official/CHIKAHAE-FE.git
cd CHIKAHAE-FE

# Install dependencies
npm install

# Setup environment variables
cp .env.example .env

# Start development server
npm run dev
```

<details>
<summary>환경 변수 설정</summary>

```env
VITE_KAKAO_APP_KEY=your_kakao_app_key
VITE_API_BASE_URL=your_api_base_url
VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_FIREBASE_PROJECT_ID=your_firebase_project_id
```

</details>
